# HTMLCriticalTowerDefence
Based on Critical Tower Defence by Jiratthee
# How It Works
This HTML game is in a "sandbox" phase and to play this sandbox, you load the page and you can see how the tower defence works right now. This is a "game" where you can place towers and watch them deal with the preset waves of enemies. There is a menu on the left which you can use to change the color of the projectiles. I added a movement system using the W, A, S and D keys. You can also zoom using the "-" button on your keyboard and the "=" (+) button. This lets you zoom from 0.5x to 2.0x. I also changed the map to fit the spooky theme for hackclub Terra!
# Inspiration
I was once bored on roblox because of all of the brain rotting slop on the front page. That was before I found out about better discovery. In better discovery, I looked up some tower defence games that looked cool, and that when I stumbled upon Critical Tower Defence. Critical TD was a really well made game because it had many mechanics that complicated the game but not that many where it made the game too hard to follow. Because I liked Critical TD so much, I decided to try to code a web game about it so that people can enjoy it even if they are on managed devices that do not allow games (me and my friends in school rn lol). So I am in progress of making this game and I am really looking forward to the following weeks!
