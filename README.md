# HTMLCriticalTowerDefence
Based on Critical Tower Defence by Jiratthee
# How It Works
This HTML game is in a "sandbox" phase and to play this sandbox, you load the page and you can see how the tower defence works right now (Without the towers). There is a menu on the left which you can use to spawn different kinds of enemies and also you can spawn custom enemies. For now, all you can see in the game is the path, the enemies (and their hp) and the base HP.
